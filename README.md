### 2. Powerful Extension Capabilities

**Remote Log Debugging and Firmware Upgrades**  
Supports a wide variety of devices, equipping developers with indispensable tools.

**tsc-cli Command Line Utility**  
The embedded tsc-cli tool offers users flexible command-line interfaces for device management tasks, easily integrating with embedded IDE environments such as VSCode and Keil, significantly boosting management and development efficiency:

- Use `tsc-cli usb dfu` to quickly switch devices to DFU mode.
- Upgrade device firmware with `tsc-cli flash <path>`.
- Monitor device messages in real time with `tsc-cli serial monitor`.
- View the list of currently connected devices using `tsc-cli serial list`.
